# DM Sans

Static instances (Regular, Italic, SemiBold, SemiBold Italic; optical size 14) of the DM Sans variable
fonts, made by `../make-static-fonts.py` from the brand kit (`branding/fonts/dmsans`) and, for the
italics, Google Fonts' `ofl/dmsans/DMSans-Italic[opsz,wght].ttf`. SIL Open Font License 1.1, in
`LICENSE.txt`. The text engine cannot select a weight or optical size from a variable font, which is
why these are static.
