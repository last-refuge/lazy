# Lazy voice and copy

## Voice

Lazy sounds like a helpful teammate: direct, warm and unhurried. Lead with the information a person needs, then explain the next step. Use familiar words and short sentences. Personality comes from care and clarity; keep jokes out of errors, permissions and security-related copy.

| Principle | Write this | Avoid |
| --- | --- | --- |
| Clear | Message your team. | Unlock seamless collaboration. |
| Warm | Welcome to your workspace. | User initialization complete. |
| Specific | Your message is waiting to send. | Something happened. |
| Calm | You’re all caught up. | You crushed your inbox! |
| Honest | Reconnecting… | Back online! when recovery is incomplete |
| Useful | Try again. Your draft is saved. | Oopsie. Moss dropped it. |

Use **Lazy** in prose and **Moss** for the mascot. Keep “Soft Signal” in design documents. Write “workspace”, “channel”, “direct message”, “thread” and “message” in sentence case. Avoid inventing new names for familiar chat features.

## Marketing copy

**Hero headline:** Good work. Easy conversation.

**Supporting line:** A little less noise. A lot more human.

**Product description:** A native place for channels, messages and the people you work with.

**Longer introduction:** Bring your team’s conversations together in Lazy. Follow channels, send a direct message, and keep replies in threads—so it’s easier to find the people and conversations you need.

**CTA vocabulary:** Get Lazy; Explore the app; Create a workspace; Sign in; Invite people.

Use “Get Lazy” only where there is a working installation path. Name the supported platform when a download action needs it. Add statements about speed, availability, privacy or other product behavior only when implementation and release documentation support them.

## Product copy library

| Situation | Heading | Supporting copy / action |
| --- | --- | --- |
| Welcome | A good place to start. | Find your people and say hello. / Browse channels |
| Empty channel | Start the conversation. | Send the first message in this channel. |
| No direct messages | Say hello. | Find a teammate and send them a message. / Find people |
| Empty thread inbox | You’re all caught up. | Replies to threads you follow will appear here. |
| No search results | No messages found. | Try another word or change your filters. |
| Workspace invitation | You’re invited. | Join your team’s workspace in Lazy. / Join workspace |
| Offline | Waiting for a connection. | Your message will send when the connection returns. |
| Reconnecting | Reconnecting… | Your conversations will update when you’re back online. |
| Failed request | That didn’t work. | Try again in a moment. / Try again |
| Upload failed | Couldn’t upload this file. | Check your connection and try again. |
| Destructive confirmation | Delete this message? | This removes the message from the conversation. / Delete message / Cancel |

These are reusable copy patterns, not substitutes for checking actual behavior. For example, promise automatic sending or saved drafts only where the product guarantees them. Substitute the concrete failure reason whenever one is available.

## Writing mechanics

- Use sentence case for headings, navigation, buttons and form labels.
- Label actions with a verb and an object when the context is unclear.
- Use an ellipsis only for an ongoing process or a command that opens a dialog.
- Prefer “you” and “your team” to “users”. Avoid blaming a person for recoverable errors.
- Pair status with concrete words; color alone cannot tell the story.
- Keep essential copy understandable without Moss, an icon or an illustration.
- For accessibility labels, describe the action: “Search messages”, not “Magnifying glass”.

## Moss and copy

Moss can welcome a person, share a quiet “all caught up” moment or celebrate a completed action. Keep interface copy in Lazy’s voice rather than having the mascot speak in first person. Use Moss sparingly so a helpful companion does not become a distraction.
